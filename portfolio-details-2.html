Sistema de Gestión del Proceso Clave para el LIEE (INAOE)

Este proyecto consistió en el diseño e implementación de un sistema web integral de gestión para el Laboratorio de Iluminación y Eficiencia Energética (LIEE) del Instituto Nacional de Astrofísica, Óptica y Electrónica (INAOE). El LIEE realiza ensayos eléctricos especializados para sistemas de iluminación en estricta conformidad con las normas NOM-030 y NOM-031. El objetivo fundamental fue automatizar la planificación, ejecución y análisis de estas pruebas, permitiendo una trazabilidad completa desde la solicitud inicial del cliente hasta la entrega del informe final. Este sistema fue desarrollado en un periodo de 3 a 4 meses empleando la metodología ágil Extreme Programming (XP).

Arquitectura y Desarrollo del Sistema

  • Desarrollo Full-Stack (Backend y Frontend): La lógica del servidor y las reglas de negocio se construyeron utilizando PHP a través del framework CodeIgniter 4, utilizando Composer para la gestión eficiente de paquetes. El lado del cliente se fortaleció con JavaScript, implementando librerías como jQuery y jsPDF para la interacción de formularios y conversión de documentos.
  • Arquitectura de Bases de Datos Dual: Para optimizar el rendimiento, se diseñó un modelo híbrido. Se utilizó MySQL (gestionado con phpMyAdmin) para la estructura relacional del flujo de trabajo, y MongoDB, una base de datos no relacional, específicamente para el guardado y gestión de los archivos PDF generados.
  • Gestión de Roles y Seguridad: Se desarrollaron módulos independientes e interfaces personalizadas para los diferentes actores del proceso: Clientes, Administradores e Ingenieros. Esto garantiza que cada usuario solo acceda a la información y acciones que le corresponden en tiempo real.
  • Integridad de Datos: Se integró la herramienta SQLBackupAndFTP para asegurar la información crítica mediante la generación de respaldos automáticos de la base de datos principal.

Impacto y Resultados Operativos

  • Centralización Operativa: Toda la información de los servicios y órdenes de trabajo quedó consolidada en un solo repositorio digital seguro y accesible.
  • Eficiencia y Trazabilidad: El seguimiento manual fue reemplazado por un flujo digital que optimizó los tiempos de respuesta y la eficiencia general de las tareas del personal técnico.
  • Integración del Cliente: Se mejoró sustancialmente la atención al cliente al brindarle una plataforma para consultar el progreso exacto de sus servicios en tiempo real.
